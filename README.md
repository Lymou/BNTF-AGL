# Multiview Clustering Integrating Biorthogonal Nonnegative Tensor Factorization and Anchor Graph Learning

:computer: This repository contains the MATLAB code for BNTF-AGL introduced in the following paper 

```html
Y.M. Liao, W Li, Q.L. Luo. "Multiview Clustering Integrating Biorthogonal Nonnegative Tensor Factorization and Anchor Graph Learning". IEEE Transactions on Neural Networks and Learning Systems, 2026. Online  
```

:link: DOI: https://doi.org/10.1109/TNNLS.2026.3713805 

### Preparation 
* **Windows 64bit** 
* **Example usage**:

```MATLAB
Please unzip the project and add it to the MATLAB path first, and then run the main.m.
```
